# 共通法モジュールカタログ ― 法体系のDRYリファクタリング素材集

現行法律2,100本・96,780条を文単位でクローン検出し（可変部＝大臣名・条番号・金額等をマスクして正規化）、
8法以上に複製されている定型文619種を機能別31モジュールに分類しました。
ソフトウェアでいえば「各ファイルにコピペされている関数を洗い出し、ライブラリに切り出す準備をした」状態です。

| 指標 | 値 |
|---|---|
| クローン文（8法以上に複製） | 619種 |
| 機能モジュール | 31種 |
| いずれかのモジュールを含む法律 | 1,542法 / 1,985法（78%） |
| 最大モジュール（罰則定型）の複製先 | 920法・4,164箇所 |

変種の実例つきのカタログは [html/module-catalog.html](html/module-catalog.html)、
機械可読データは [`results/module_catalog.json`](../results/module_catalog.json)（31モジュール）と
[`results/clone_catalog.json`](../results/clone_catalog.json)（619クローン文）にあります。

## DRY違反の「実物」

同じ機能なのに表記が揺れている実例です。

- 身分証提示モジュール（M10・516法）には「関係人／関係者」「これを提示／提示」「請求があるとき／あつたとき」等の変種が12種。
- 犯罪捜査解釈禁止（M09・584法）には「解してはならない」162法 対 「解釈してはならない」128法という二大方言が併存。

機能は同一で、実装がコピペで分岐した状態です。ソフトウェアなら即リファクタリング対象になります。

## 実装アプローチ（現実的な移行経路）

- 参照方式（import）：新規立法から共通法参照を義務化する。法制局の審査基準に「例文コピペ禁止・共通法○条を引用」のリンター規則を入れる。既存法は改正機会ごとに置換（strangler fig）。
- オーバーライド方式（デジタル手続法型）：個別法を書き換えずに「個別法の規定にかかわらず〜できる」と横断上書きする1本を通す。公示方法・電磁的記録定義はこの型が速い。
- テンプレートの機械可読化：例文（内閣法制局テンプレート）を法令XML上で「この文は共通テンプレ#Xのインスタンス」とアノテーションする。切り出し前でも一括改正のコストが激減する。

## 留意

- 検出は正規化後の完全一致のみ。言い回しが少し違う実質的クローンは拾えていないため、ここの数字は下限値です。
- 罰則の法定刑や検査対象はモジュールの「引数」であり、共通化とは「引数だけを各法に残す」ことです。実体的な差異を消す提案ではありません。
- 対象は法律のみ（政令・省令を含めれば複製規模はさらに大きい）。データは2025年5月版の法令ミラー準拠です。
