# アナログ規制の概念採掘 ― 単語ではなく「書かれ方」で法律を洗う

デジタル臨時行政調査会のアナログ規制一括見直しは「フロッピーディスク」「対面」といった単語の検索・一括置換でした。
本分析はその一歩先で、概念（コンセプト）を検索単位にして、現行法律2,100本の全文から
「言い回しそのものがアナログ前提になっている条文」を機械的に採掘する試みです。

| 指標 | 値 |
|---|---|
| 現行法律（e-Gov全文XML） | 2,100本 |
| スキャンした条文 | 96,780条 |
| アナログ概念 | 25（うちLLM発見が7） |
| 候補ヒット（条×概念） | 24,179 |
| 電磁的代替規定が一切ない法律 | 899法 |

## 手法：3層パイプライン

| 層 | やること |
|---|---|
| ① 概念カタログ | アナログ前提の「書かれ方」を25概念に体系化。デジタル庁の7類型を包含して拡張（`concepts.json`） |
| ② 全文スキャン | 概念ごとの再現率重視の正規表現網を96,780条に適用。条・法令ごとに電磁的代替規定の有無を併記 |
| ③ LLM判定 | 並列エージェント10体。候補287件の真陽性判定に加え、未ヒット400条の精読で新概念を発見 |

データはe-Govの全法令XML（法律のみ・2025年5月版ミラー）。本則のみを対象とし、政令・省令は未収録です。
アナログ規制の物量は省令層にあるため、そこが次の一手の筆頭になります。

## 概念体系：どういう書かれ方が、どのアナログ前提か

「対面」「フロッピーディスク」のような明白な単語ではなく、言い回し・付随要件・制度前提としてアナログ性が埋まっている。
それを概念単位で捕まえます。抜粋（★は単語検索に掛からない例、LLM発見はLLMが未ヒット条文の精読から見つけた概念）。

| 概念 | 条文の書かれ方（例） | 何を阻むか |
|---|---|---|
| C01 対面・出頭 | ★「〜の面前で」「立会いをもってしなければ効力を生じない」 | ウェブ会議・遠隔立会い |
| C02 実地・立入 | ★「実地に調査」「事業所に立ち入り、帳簿書類を検査」 | センサー・遠隔監視 |
| C03 書面交付 | 「書面により」「文書をもって」 | 電子申請・電子交付 |
| C06 備置き・縦覧 | ★「事務所に備え置き、請求があったときは閲覧させ」 | ウェブ公表 |
| C08 公告限定 | 「官報に掲載」「日刊新聞紙に掲載」 | 電子公告 |
| C15 口頭・読み聞かせ | ★「これを読み聞かせ」「口述を筆記」 | 非同期の内容確認 |
| C17 経由提出 | ★「知事を経由して提出」「事業主を経由して申出」 | システム直結・ワンスオンリー |
| C19 会議体開催（LLM発見） | ★「半数以上が出席する総会」「期日を開き呼び出さなければ」 | 書面決議・電子投票 |
| C20 所在地管轄（LLM発見） | ★「所在地を管轄する知事に」「市町村長を経て」 | どこでも申請 |
| C21 刻印・封印（LLM発見） | ★「検査済証印を刻付」「証紙を貼り付けて消印」 | 電子タグ・DB照会 |
| C22 手帳・証票（LLM発見） | ★「被保険者証を添付→券面に記載して返付」「返納」 | 資格情報のDB管理 |
| C24 くじ・発送時刻（LLM発見） | ★「願書の発送の日時の先後」「公正な方法でくじ」 | 電子受付タイムスタンプ |

全25概念（C01〜C25）の定義・正規表現網・障壁理由は [`concepts.json`](../concepts.json) に機械可読で入っています。

## 結果 I：隠れアナログ規制の実物

単語検索ではゼロヒットの層から、言い回しが障壁になっている代表例。

### 民法 第853条・第871条

> 財産の調査及びその目録の作成は、後見監督人があるときは、その立会いをもってしなければ、その効力を生じない。

「対面」という語なしに物理的同席が効力要件になっています。遠隔立会いの可否は条文上不明です。

### 健康保険法 第43条の2

> その使用される事業所の事業主を経由して保険者等に申出をしたときは……

本人から保険者へのシステム直結を阻む紙リレー設計。「を経由して」は法律全体で507箇所あります。

### 民法 第465条の6（事業保証の公正証書）

> 公証人が、保証人になろうとする者の口述を筆記し、これを読み聞かせ、又は閲覧させること。

音声・同期・同所がすべて前提。公証人法30条・52条の「面前」「立ち会わせ」も同系です。

### 鉱業法 第27条

> ……願書の発送の日時の先後により定める。……先後が明らかでないときは……公正な方法でくじを行い……

郵送時刻の競争と対面抽選が優先権のルールになっています。電子受付のタイムスタンプで置換できます。

### 介護保険法 第32条

> ……被保険者証を添付して……要支援認定をしたときは、その結果を……被保険者証に記載し、これを返付するものとする。

紙証憑の「添付→券面記載→返付」という往復運用が法定されています。資格DB化を阻む型で、同型が803条文・332法に分布します。

## 結果 II：どの法律にどれだけ堆積しているか

候補は1,426本の法律に分布し、うち899本は法令内に電磁的代替規定（「電磁的方法」「電子情報処理組織」等）が一切ありません。

| 法律 | 概念数(/25) | 条数 | 電磁的代替規定 |
|---|---|---|---|
| 地方税法 | 22 | 408 | あり |
| 出入国管理及び難民認定法 | 22 | 204 | あり |
| 金融商品取引法 | 21 | 512 | あり |
| 公職選挙法 | 21 | 237 | あり |
| 地方自治法 | 19 | 161 | あり |
| 国税通則法 | 18 | 124 | あり |
| 土地収用法 | 16 | 91 | なし |
| 捕虜等取扱い法 | 14 | 73 | なし |

「代替規定なし × 多概念」の法律（土地収用法など）が優先ターゲットです。

## 結果 III：LLM検証 ― 候補網はどこまで信用できるか

18概念×16条＝287件をエージェントが精読判定しました。適合率は概念により25〜81%（全体51%）。
真陽性のうち61%が「デジタル化可能性 high」で、low は刑事手続の身柄・危険物の実物検査・遺言の真意確認など、
物理性それ自体が保護法益のものに限られました。

| 精度帯 | 概念 | 含意 |
|---|---|---|
| 81% | 官報公告(C08)・経由提出(C17)・書面交付(C03) | そのまま一括改正候補の母集団に使える |
| 50〜75% | 対面・出頭(C01)・押印(C05)・携帯提示(C09)・実地(C02)ほか | 罰則条・準用条の機械フィルタで実用水準へ |
| 25〜40% | 原本部数(C04)・常駐専任(C10)・講習(C12)・郵便(C14)・持参(C18) | 偽陽性の型が明確（「副本部長」「常時勤務」「定期積金」の誤ヒット等）で改善が容易 |

### 検証から挙がった一括改正候補の型

- 立法格差型：同型手続なのに手当てが分かれる。信託法・投信法は電磁的議決権行使あり、農住組合法50条はなし。
- 効力はアナログ側型：種苗法57条の2は公示の効力を官報に係らしめ、ネット公表は事後周知扱い。会社法820条系は電子公告が「催告省略要件」にしかならない。
- 電子化規定の陳腐化型：建設業法39条の4。電子手続の特例自体が「磁気ディスクの提出」前提。
- 象徴型：公的個人認証法3条の2。電子証明書の発行申請が市町村長・領事官の窓口経由。
- 横断改正型：実用新案法54条ほか産業財産権四法の「特許印紙をもつて納付」。倒産・会社非訟の裁判書送達（会社法897条・民事再生法30条・破産法179条）。

詳細は [`results/llm_verification.md`](../results/llm_verification.md) にあります。

## 結果 IV：発見ループ ― LLMが網を広げる

25概念のどれにもヒットしなかった条文400条を精読させ、54件の「網に載っていないアナログ前提」を発見しました。
集約した7概念（C19〜C25）を網に追加して再スキャンしたところ、4,177条の新規候補が追加で採掘されています。
会議体開催前提1,015条、所在地管轄1,256条、手帳・証票の往復運用803条。いずれも従来のキーワード型見直しではゼロヒットの層です。

採用を見送った分（場所固定の許可、執行場所の限定、店舗前提の定義〈商法4条はEC専業者が「商人」定義から漏れる〉、
同時申請、紙台帳への「記載」限定、無資料口頭陳述〈民訴法203条〉等）も
[`results/llm_discoveries.json`](../results/llm_discoveries.json) に記録してあり、次の反復で網に加えられます。

## 次の一手

- 省令・政令への適用。アナログ規制の物量の本丸。e-Gov法令API v2の全法令種別で同じパイプラインを回す。
- 全24,179候補のLLM全件判定。1件数百トークンで現実的。今回はサンプル287件にとどめた。
- 偽陽性の機械フィルタ。罰則条・準用条・定義条の除外、「副本部長」等の負の先読み。
- 同型手続の横並び比較。立法格差の系統検出から改正の順序を提案する。
